# i18n (bahasa antarmuka)

Preferensi bahasa global: **Global Settings → Appearance → Bahasa**.
Pilihan disimpan di `app_settings.ui_preferences.language` (`id` | `en`) dan
dicache di `localStorage` (`rnd.language:v1`) supaya teks pertama yang tampil
sudah memakai bahasa pilihan. Perubahan berlaku langsung tanpa restart.

## Struktur

```
web/src/lib/i18n/
  config.ts          # Locale, default (id), opsi bahasa, localStorage
  translate.ts       # interpolate + createTranslator (fallback id → key)
  types.ts           # Locale, MessageDict, Translator
  I18nProvider.tsx   # <I18nProvider> + useI18n() → { t, locale, setLocale }
  messages/
    index.ts         # gabungan semua kamus
    id/index.ts      # gabung domain (Bahasa Indonesia — teks asli UI)
    en/index.ts      # gabung domain (English)
    id/<domain>.ts   # per domain: common, nav, language, app, chat, explorer,
    en/<domain>.ts   # documents, tickets, git, workflow, terminal, review,
                     # settings, settingsAdvanced
```

`I18nProvider` dipasang di `web/src/main.tsx` (di dalam `ThemeProvider`).

## Memakai di komponen

```tsx
import { useI18n } from "@/lib/i18n";

export function Example() {
  const { t } = useI18n();
  return <button title={t("explorer.tree.delete")}>{t("common.delete")}</button>;
}
```

- Interpolasi: `t("tickets.kanban.count", { count: 3 })` → template `"{count} tiket"`.
- Konstanta modul (array opsi/menu) menyimpan `labelKey`/`descriptionKey`, lalu
  diterjemahkan saat render: `t(item.labelKey)`.
- Helper non-komponen menerima `t: Translator` sebagai parameter.
- Key baru **wajib** ditambahkan ke `messages/id/<domain>.ts` **dan**
  `messages/en/<domain>.ts` dengan set key identik.

## Yang tidak diterjemahkan

Nilai data dan istilah teknis: nama produk (Jira, ClickUp, Docmost, Notion,
Confluence, MCP, LLM, Git, Cursor), path/nama file, key tiket, status internal
workflow (`running`, `success`, …), nilai enum yang dikirim ke backend
(`light`, `vs-dark`, `stdio`, `api`, `zsh`, …), isi log/diff, dan `console.*`.

## Guard

`web/src/lib/i18n.test.ts` (vitest) memeriksa:

1. set key `id` dan `en` identik,
2. tidak ada teks kosong,
3. setiap `t("…")` di komponen punya entri di kedua bahasa.

```bash
cd web && npx vitest run src/lib/i18n.test.ts
```

## Belum tercakup

Dua file terbesar (`web/src/App.tsx` ±71 KB dan `web/src/components/ChatSidebar.tsx`
±60 KB) belum bisa dikonversi: tool `read_file` memotong berkas >±50 KB sehingga
isi lengkapnya tidak bisa dibaca/ditulis ulang dengan aman. Sisa teks di kedua
file mengikuti bahasa aslinya (Indonesia). Rencana: pecah dulu komponennya
(`ChatComposer`, `ChatStepList`, tab shell) sampai tiap file < 45 KB, lalu
konversi seperti komponen lain. Lihat tiket `LOCAL-8A9A58`.

### Menunggu wiring: tab Workspace

`web/src/components/WorkspaceOverview.tsx` sudah siap (memakai `useI18n()` dan
key `app.workspaceOverview.*`, termasuk "Mulai dari sini" / "Start here").
`App.tsx` masih menyimpan salinan lokalnya, jadi yang tampil tetap teks lama
sampai dua langkah ini dikerjakan:

1. Tambah `import { WorkspaceOverview } from "@/components/WorkspaceOverview";`.
2. Hapus blok `function WorkspaceOverview({` … sampai tepat sebelum
   `function lspBadgeLabel(` (termasuk `StatCard`).

Props identik (`detail`, `onOpenSettings`), jadi pemakaian `WorkspaceOverview`
di `renderTab` tidak perlu diubah.
