# i18n (bahasa antarmuka)

Preferensi bahasa global: **Global Settings → Appearance → Bahasa**.
Pilihan disimpan di `app_settings.ui_preferences.language` (`id` | `en`) dan
dicache di `localStorage` (`rnd.language:v1`) supaya teks pertama yang tampil
sudah memakai bahasa pilihan. Perubahan berlaku langsung tanpa restart.

## Struktur

```
web/src/lib/i18n/
  config.ts          # Locale, default (id), opsi bahasa, localStorage
  translate.ts       # interpolate + createTranslator (fallback id → key)
  types.ts           # Locale, MessageDict, Translator
  I18nProvider.tsx   # <I18nProvider> + useI18n() → { t, locale, setLocale }
  messages/
    index.ts         # gabungan semua kamus
    id/index.ts      # gabung domain (Bahasa Indonesia — teks asli UI)
    en/index.ts      # gabung domain (English)
    id/<domain>.ts   # per domain: common, nav, language, app, chat, explorer,
    en/<domain>.ts   # documents, tickets, git, workflow, terminal, review,
                     # settings, settingsAdvanced
```

`I18nProvider` dipasang di `web/src/main.tsx` (di dalam `ThemeProvider`).

## Memakai di komponen

```tsx
import { useI18n } from "@/lib/i18n";

export function Example() {
  const { t } = useI18n();
  return <button title={t("explorer.tree.delete")}>{t("common.delete")}</button>;
}
```

- Interpolasi: `t("tickets.kanban.count", { count: 3 })` → template `"{count} tiket"`.
- Konstanta modul (array opsi/menu) menyimpan `labelKey`/`descriptionKey`, lalu
  diterjemahkan saat render: `t(item.labelKey)`.
- Helper non-komponen menerima `t: Translator` sebagai parameter.
- Key baru **wajib** ditambahkan ke `messages/id/<domain>.ts` **dan**
  `messages/en/<domain>.ts` dengan set key identik.

## Yang tidak diterjemahkan

Nilai data dan istilah teknis: nama produk (Jira, ClickUp, Docmost, Notion,
Confluence, MCP, LLM, Git, Cursor), path/nama file, key tiket, status internal
workflow (`running`, `success`, …), nilai enum yang dikirim ke backend
(`light`, `vs-dark`, `stdio`, `api`, `zsh`, …), isi log/diff, dan `console.*`.

## Guard

`web/src/lib/i18n.test.ts` (vitest) memeriksa:

1. set key `id` dan `en` identik,
2. tidak ada teks kosong,
3. setiap `t("…")` di komponen punya entri di kedua bahasa.

```bash
cd web && npx vitest run src/lib/i18n.test.ts
```

## Berkas besar: `App.tsx` & `ChatSidebar.tsx`

Dua berkas terbesar (`web/src/App.tsx` ±71 KB, domain `app` dan
`web/src/components/ChatSidebar.tsx` ±60 KB, domain `chat`) melewati batas baca
tool: `read_file` memotong berkas >±50.000 karakter, sedangkan `write_file`
menimpa seluruh isi berkas. Menulis ulang berkas itu dari chat akan menghapus
ekor berkasnya (`DocumentTab`/`TicketTab`/`SettingsTab` di App.tsx, composer
footer di ChatSidebar).

Karena itu konversinya dikerjakan oleh codemod yang membaca & menulis berkas di
runtime (tanpa batas tool):

```bash
deno task i18n:codemod              # dry-run: laporan rule + sisa teks hardcoded
deno task i18n:codemod --write      # terapkan ke kedua berkas
deno task i18n:codemod --inventory  # hanya daftar teks yang belum di-i18n
cd web && npx vitest run src/lib/i18n.test.ts
```

`scripts/i18n-apply.ts`:

- mengganti literal menjadi `t("…")` untuk domain `app` dan `chat`; tiap rule
  menyatakan jumlah kemunculan yang diharapkan (`expect`) dan rule yang
  jumlahnya tidak sesuai **dilewati** (tidak menebak),
- menambahkan `useI18n()` + `const { t } = useI18n();` dan
  `import { useI18n, type Translator }` (helper non-komponen seperti
  `lspBadgeLabel`/`readAttachment` memakai parameter `t: Translator`),
- mem-wire `WorkspaceOverview` (tambah impor, hapus salinan lokal
  `WorkspaceOverview` + `StatCard`, buang impor `Card` yang jadi tidak terpakai),
- memeriksa "anchor" (`function DocumentTab(`, `function TicketTab(`,
  `function SettingsTab(`, `</aside>`, …) sebelum menulis; kalau ada yang hilang,
  penulisan berkas dibatalkan,
- menulis atomik (`*.i18n.tmp` → `rename`),
- mencetak **sisa teks user-visible** (nomor baris + teks) sehingga bagian ekor
  yang tidak terbaca pun bisa diinventaris tanpa `read_file`.

Kamus `app` dan `chat` (id + en) sudah lengkap untuk seluruh teks di bagian yang
terbaca. Sisa teks di ekor berkas muncul pada laporan `sisa teks hardcoded`;
tinggal ditambahkan sebagai rule baru di `scripts/i18n-apply.ts` berikut key
pasangannya.

### Status tab Workspace

`web/src/components/WorkspaceOverview.tsx` sudah ter-i18n-kan (key
`app.workspaceOverview.*`, termasuk "Mulai dari sini" / "Start here") dengan
props identik (`detail`, `onOpenSettings`), jadi pemakaiannya di `renderTab`
tidak berubah. Penggantian salinan lokalnya dilakukan oleh langkah struktural
codemod di atas.
